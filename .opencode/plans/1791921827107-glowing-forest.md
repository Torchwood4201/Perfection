# Perfection — Improvement Plan

## Goal
Keep the 5×5 Perfection game static (`open index.html`, no build), keep branding/board art, and fix stability → mobile/a11y → UX polish → optional features, each phase independently playable.

Critical files: `Perfection/index.html` (54 lines), `Perfection/script.js` (~537 lines, `PerfectionGame`), `Perfection/style.css` (~543 lines), assets under `Perfection/assets/{Board,shapes,timer,logos,sounds}`.

## Phase 0 — Test harness (do first, ~30 min)
- Expose `window.__game = this` in `PerfectionGame` constructor (1 line, test-only).
- Add manual Playwright smoke used for all phases: `python3 -m http.server` + `playwright-cli open http://localhost:3002/index.html`, then assert: 25 slots/shapes, Start → `#timerNumber` counts down, correct drop → `Correct!`, wrong drop → `Wrong shape!`, full board → `.game-board.win` + win message, no `response.status>=400`, no `pageerror`.
- Success: zero 404s, zero console errors on reload.

## P0 — Correctness / stability (quick wins, ~3h)
1. **Duplicate listeners + leaked timers** — `script.js:113-144,355-370`
   - Call `setupEventListeners()` only from `init()`, not `resetGame()`; switch to delegation (one listener on `#gameBoard`, one on `#shapeTray`); guard global `document dragover/drop` with once-only flag.
   - Add `this.timeouts = new Set()` + `later(fn,ms)` helper; `clearAllTimers()` in `resetGame()/endGame()` covering win-delay (`:464`), message hide (`:489`), bounce/grid/pop/spill timeouts. Cancel pending win on reset.
   - Verify: Start→Reset×5→Start, one placement = one message; no acceleration.
2. **Constants + shuffle** — `script.js:10,70-72,91,345,473`
   - Add `CONFIG = {ROWS:5, COLS:5, TIME:60, WIN_DELAY:1000}`; replace magic `5/25/60/1000`; Fisher-Yates instead of `sort(()=>Math.random()-0.5)`; drop unused `setData(outerHTML)` or store id string.
   - Verify: win on last second stays win.
3. **Audio robustness** — `script.js:20-22,341-343`
   - Lazy-init `Audio` on first Start click; add mute toggle; add missing snap sound in `placeShape()`; rename `ending pop.mp3` → `ending-pop.mp3` (same for `main logo.png`, `time dial.png` or URL-encode); silent visual fallback on `play()` rejection.
   - Verify: blocked audio still playable, no unhandled rejections.
4. **CSS consolidation** — `script.js:500-537` → `style.css`
   - Move injected `<style>` (pulse/fadeOut/gridPulse, `.message.info/error/success`) into `style.css`; add `prefers-reduced-motion` disable.
   - Verify: screenshot diff clean.

## P1 — Mobile input + accessibility (~7-9h, core value)
5. **Pointer drag (touch/mouse/pen)** — `script.js:146-241`, `style.css:251-267`
   - Keep HTML5 DnD as fallback; add `pointerdown/move/up` + `setPointerCapture` ghost clone, `touch-action:none`, hit-test via `elementFromPoint().closest('.slot')`, reuse exact-match check.
   - Verify: touch drag on mobile viewport places tile; desktop DnD still works.
6. **Keyboard + ARIA** — `index.html:39-49`, `script.js:63-111`
   - Slots `role=gridcell tabindex=0 aria-label="Slot row R col C"`, tray `role=listbox`, shapes `role=button tabindex=0`; Enter/Space select, arrows move, Enter drop, Esc cancel; `#message role=status/alert`; `:focus-visible` outline; non-color cues (`✓/✕` + border style, not just green/red); timer contrast chip + `tabular-nums`.
   - Verify: full Tab-only win; axe/Lighthouse ≥95.
7. **Tap-to-place fallback** (ships with #5): tap shape → tap slot. Also fixes keyboard path. Verify on touch emulator.

## P2 — UX polish (~3h)
8. **Fluid layout, remove zoom hack** — `index.html:11-15`, `style.css:40-52,202-243,425-467`
   - Delete `zoom-note`; board `width:min(92vw,412px); aspect-ratio:1; background-size:cover`; shapes `clamp(38px,12vw,78px)`; controls wrap; tray `max-height:30vh; overflow:auto`. Replace note with `<details>How to play</details>`.
   - Verify viewports 360×640 / 768×1024 / 1440×900 at 100% zoom, no horizontal scroll.
9. **Messages + effects** — `script.js:283,352,369,385-387,292-333,395-445`
   - `showMessage(text,type,{sticky})`: auto-hide only info/success/error; win/lose sticky; clear previous timeout; persistent `Placed N/25` counter instead of per-tile `Correct!` spam; move inline `cssText` to classes; cleanup spilled/grid/pop nodes on reset.
   - Verify: win persists >5s; lose→reset leaves no `.spilled-tile`.

## P3 — Optional features (each shippable, ~5h total)
10. **Best score** (`localStorage perfection.best`, chip next to switch).
11. **Difficulty** (`easy 3×3/45s`, `normal 5×5/60s`, `blitz 5×5/30s` via `<select>`, grid via `repeat(n,1fr)`).
12. **Help `<dialog>` + Pause** (pause clears interval, freezes input, auto-pause on `visibilitychange`).
13. **README rewrite** (run instructions, controls, structure, tests; move coursework prompt to `docs/assignment.md`); rename typo paths (`refrance`, `empey_slots_emptey`) with fallback copies.

## Order
1. Phase 0 → P0 (#1-4) — ~1 day, highest ROI.
2. P2 quick wins (#8-9 partial) + P1 non-color/contrast.
3. P1 pointer DnD (#5+#7), then keyboard (#6).
4. P2 responsive (#8 full), then P3 in any order.

## Risks
- Pointer DnD is the only large item; keep HTML5 fallback until touch path passes desktop regression.
- Asset renames (spaces/typos) must keep old filenames as copies until CSS/JS refs + Playwright 404 check pass.
